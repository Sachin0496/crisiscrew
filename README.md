# CrisisCrew

Customers notice outages before dashboards do. CrisisCrew treats incoming support tickets as incident telemetry. It correlates complaints that describe the same failure in different words, opens one incident, investigates the likely cause, and hands high-risk decisions to a human.

> **Status (2026-09-22): there is no product code yet.** CrisisCrew is a Stage 2 finalist in The Great Agent Hackathon (Freshworks). The rules say the Stage 2 build must happen from scratch during the 24-hour on-site sprint, which starts on 2026-09-25 at 11:00 IST. Until then, this repo holds:
>
> - `prototype/`: the Stage 1 submission, archived unchanged. It's a scripted demo; its README explains exactly what was scripted.
> - `docs/`: the design and build plan, written before the event. They contain ideas only, no code.
>
> Every commit that adds code will be timestamped after kickoff.
